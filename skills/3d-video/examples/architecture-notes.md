# Example evidence

## service-example

This is a deliberately fictional six-component commerce service. The client sends an order through API/access control/order processing. Order processing writes a database, dispatches background work and returns a result. It is not evidence of any real repository or deployment.

## pipeline-example

This fictional data pipeline uses storage, queue, compute cluster, warehouse and query service. Archive storage is explicitly planned and is not executed by the animated flow.

For a real project replace this note with repo-relative code/document locators and set each node's status from evidence. Do not treat these examples as generic facts that every codebase must match.
